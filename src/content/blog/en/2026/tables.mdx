## Comparison

An empty first header turns the first column into row labels.

|                    | Polling                                          | Webhooks                                                     |
| ------------------ | ------------------------------------------------ | ------------------------------------------------------------ |
| Latency            | Up to one interval, 30 seconds by default        | A few hundred milliseconds after the event                   |
| Load on the server | One request per client per interval, idle or not | One request per event                                        |
| Missed events      | None: the next poll catches up                   | Lost unless the sender retries, so you need a reconciler job |
| Local development  | Works out of the box                             | Needs a tunnel such as `ngrok` to reach your machine         |
| Who maintains it   | The client team                                  | Both teams, plus whoever owns the queue                      |

## Code in cells

Inline code keeps its frame inside a cell.

| Variable                  | Default      | Read by                                           |
| ------------------------- | ------------ | ------------------------------------------------- |
| `DATABASE_URL`            | none         | The server at boot; it exits without it           |
| `CACHE_TTL_SECONDS`       | `300`        | `createCache()` in `src/server/cache.ts`          |
| `FEATURE_FLAGS_SDK_KEY`   | none         | The flag client; every flag falls back to `false` |
| `SHARED_WORKER_BUILD_URL` | `/worker.js` | The tab that boots first, to spawn the worker     |
